# أثر أكاديمي | ATHAR ACADEMY

منصة تعليمية عربية لطلاب الصف الثالث الثانوي في مصر. الشعار: «أثر في كل خطوة».

## حالة البناء

المستودع الآن في المرحلة الأولى فقط: تأسيس Next.js وTypeScript، واجهة عربية متجاوبة، PostgreSQL مع Prisma، تسجيل دخول آمن، وتجهيز حساب أول مدير بطريقة لا تتضمن بيانات اعتماد افتراضية. لا توجد بعد أكواد اشتراك أو لوحات تشغيلية أو تكاملات AI أو كويزات أو بيانات طلاب.

## البنية

- Next.js App Router وReact وTypeScript.
- Tailwind CSS مع أنماط RTL مخصصة.
- PostgreSQL وPrisma، مع ترحيل قاعدة بيانات أولي قابل للتكرار.
- NextAuth Credentials مع كلمة مرور مجزأة بـ bcrypt، ورمز جلسة قصير العمر. صلاحية المستخدم ودوره يعاد التحقق منهما من قاعدة البيانات عند كل صفحة محمية؛ لا تعتمد الحماية على الدور الموجود في المتصفح.
- حدّ دخول مستمر في PostgreSQL: خمس محاولات فاشلة لكل بريد وعنوان عميل مُجزّأين في نافذة 15 دقيقة، من دون حفظ عنوان العميل الخام.
- Zod للتحقق من مدخلات تسجيل الدخول وإعداد المدير.

## الإعداد

يتطلب المشروع Node.js 20.19 أو أحدث وPostgreSQL دائمًا. انسخ قيم أسماء المتغيرات من .env.example إلى مخزن الأسرار لدى بيئة التشغيل، ثم أضف القيم هناك فقط:

- DATABASE_URL: عنوان PostgreSQL الدائم.
- AUTH_SECRET: سر عشوائي قوي لا يقل عن 32 بايت.
- ADMIN_BOOTSTRAP_TOKEN: رمز مؤقت عشوائي لا يقل عن 32 حرفًا لإعداد أول مدير؛ لا ترسله في المحادثات ولا تضفه للمستودع.
- NEXTAUTH_URL: العنوان الأساسي للتطبيق بعد النشر.

من واجهة بيئة التطوير أو لوحة الاستضافة:

1. ثبّت الاعتماديات باستخدام npm install، ثم التزم بملف package-lock.json الناتج قبل النشر.
2. أنشئ قاعدة البيانات، ثم شغّل npm run db:deploy.
3. شغّل npm run dev للتطوير أو npm run build ثم npm start للإنتاج.
4. افتح /setup، وأنشئ أول حساب Super Admin باستخدام الرمز الموجود في مخزن الأسرار. تُغلق عملية الإعداد بعد إنشاء المدير الأول.
5. سجّل الدخول من /login. لا توجد كلمة مرور افتراضية أو حساب تجريبي.

لبيئة تطوير محلية، استخدم npm run db:migrate لإنشاء ترحيل جديد عند تغيير المخطط. لا تشغّل db:push على قاعدة إنتاج.

## الأوامر

- npm run dev — خادم التطوير.
- npm run build — توليد Prisma وبناء Next.js.
- npm run start — تشغيل البناء.
- npm run lint — فحص ESLint.
- npm test — اختبارات التحقق ومدخلات المصادقة.
- npm run db:validate — التحقق من مخطط Prisma.
- npm run db:deploy — تطبيق الترحيلات الملتزمة.
- npm run db:migrate — إنشاء ترحيل في التطوير.

## الأمان وحدود المرحلة

لا توجد أسرار أو بيانات طلاب حقيقية في هذا المستودع. لا تفعّل إعداد المدير قبل ضبط PostgreSQL والأسرار عبر لوحة الاستضافة. تعتمد حماية محاولات الدخول على أن يعيد الوكيل العكسي الموثوق ضبط رأس X-Forwarded-For؛ تحقّق من إعداد منصة النشر قبل الاعتماد على الحد لكل عنوان عميل. يجب إضافة الأدوار المستقبلية والصلاحيات على الخادم مع استعلامات مقيّدة بالمستخدم؛ لا تعتبر إخفاء عنصر في الواجهة حماية. بيانات AI ومفاتيح DeepSeek أو Gemini ليست مطلوبة في هذه المرحلة، ولا ينبغي وضعها في المتصفح أو GitHub.

الخطوة التالية بعد مراجعة المرحلة الأولى والموافقة عليها: المرحلة الثانية، أكواد الاشتراك وتفعيل حساب الطالب مع فحص حالة الاشتراك على الخادم.
